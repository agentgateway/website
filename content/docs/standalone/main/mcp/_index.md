Connect agentgateway proxies to MCP tool servers so that you can access MCP tools.

After you connect a tool server, connect an AI client to it. See the [MCP clients]({{< link-hextra path="/integrations/mcp-clients/" >}}) guide for Claude Desktop, Claude Code, Cursor, VS Code, and Devin Desktop (formerly Windsurf).
