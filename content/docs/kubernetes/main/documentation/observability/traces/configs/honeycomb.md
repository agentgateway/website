Send traces, access logs, and metrics from an agentgateway proxy to Honeycomb by following the [Honeycomb observability guide]({{< link-hextra path="/integrations/llm/observability/honeycomb/" >}}).

That guide creates an Ingest key, exports traces and access logs directly over OTLP/HTTP, and scrapes Prometheus metrics with an OpenTelemetry Collector.
