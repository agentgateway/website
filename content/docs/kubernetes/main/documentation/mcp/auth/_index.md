Authenticate MCP clients with your MCP server by using MCP auth. Agentgateway serves the OAuth metadata that MCP clients discover, validates the tokens that your authorization server issues, and adapts to the OAuth behavior of each supported identity provider.

To learn how the MCP authorization flow works, start with [About MCP auth]({{< link-hextra path="/documentation/mcp/auth/about/" >}}). Then follow the guide for your identity provider.
