> [!NOTE]
> If you run agentgateway in a Docker container, `localhost` is the agentgateway container, not your host. Set the collector host to `host.docker.internal:4317` instead. Docker Desktop resolves this name for you. On Linux, also add `--add-host=host.docker.internal:host-gateway` to the `docker run` command that starts agentgateway. Another option is to run both containers on the same Docker network and use the collector's container name as the host.
