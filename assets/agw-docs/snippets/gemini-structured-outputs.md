For OpenAI-compatible Chat Completions requests, set `response_format.type` to `json_schema` to request structured JSON from a Gemini model. {{< reuse "agw-docs/snippets/agentgateway-capital.md" >}} sends the schema to Gemini as `responseJsonSchema`. Standard JSON Schema keywords, such as `$defs`, `$ref`, `anyOf`, and `additionalProperties`, pass through unchanged. Tool definitions are handled differently. For schemas in `tools[].function.parameters`, {{< reuse "agw-docs/snippets/agentgateway.md" >}} inlines `$defs` and `$ref`, removes fields that Gemini does not support, such as `additionalProperties`, and keeps a `propertyOrdering` field that you set.
