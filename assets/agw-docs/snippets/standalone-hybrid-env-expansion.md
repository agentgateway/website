Agentgateway expands environment variable references, such as `${VAR}`, in your configuration file. In `hybrid` mode, it does not expand them in the resources that you save through the UI, the config resource API, or agctl. Agentgateway stores and uses those resources exactly as you enter them. The exception is the `params.apiKey` field of an LLM provider or model. That field can reference an environment variable, such as `$OPENAI_API_KEY`, or a file, such as `{file: $HOME/key}`, and agentgateway expands the references in both forms. In `file` mode, agentgateway expands references everywhere, because it saves every resource to the file.
